# 录音总结

把录音或转写稿整理成一份重点清楚、通俗具体、清新简约的 HTML 智能总结。

调用词：**录音总结**  
Skill 名称：`recording-content-summary`

## 能做什么

- 先提炼重点，再按主题展开详细内容。开头用多宫格呈现各个核心结论，按重要程度排序。
- 在录音基础上补充必要背景、原因分析、不同选择和具体建议，清楚区分录音事实、分析推断、外部资料与建议。
- 根据内容使用对比表、流程图、关系结构或有可靠数据支持的图表，避免只罗列抽象概念。
- 生成可离线打开的单文件 HTML，使用清淡底色、薄荷绿强调和清楚的文字层级，适配电脑与手机。
- 统一文件命名：`内容主题-YYYY-MM-DD-智能总结.html`。

## 使用方式

将本仓库作为一个完整的 skill 文件夹安装，保持下方目录结构。然后提供录音或转写稿，并输入：

```text
录音总结：请整理这份录音，先用多宫格呈现重要结论，再按主题展开。
补充能帮助理解的背景和可执行建议，输出 HTML。
```

也可以补充用途，例如“供产品团队修改页面使用”“重点整理课程中的方法与例子”，或指定篇幅与语言。

## 音频转写依赖

本 skill 提供工作流程和 HTML 模板，**不附带语音识别引擎、模型或转写服务账号**。只提供音频时，运行环境需要可用的语音识别能力，并应先验证识别质量；已有转写稿可以直接使用。

如果使用第三方服务处理音频，应说明服务和数据发送位置，并取得适用的授权。无法可靠转写时，应明确说明原因，不根据乱码或文件名编造总结。

## 输出结构

1. 主题标题与一行必要元信息。
2. 重点总结多宫格：每格一个具体结论，配一两句解释；第一格轻量强调。
3. 可选目录与按主题展开的详细总结。
4. 按需加入分析、图表、行动建议、分歧和待确认问题。
5. 资料说明与可点击来源链接。

通常按实际内容提炼 3–6 个重点；四个要点用 2×2，三个或六个短要点可用三列，手机转为单列。不为凑宫格增加重复观点。

## 文件结构

```text
recording-content-summary/
├── SKILL.md                      # 工作流程、表达要求与质量检查
├── README.md                     # 使用说明
├── agents/
│   └── openai.yaml               # 显示名称与默认提示词
├── assets/
│   └── summary-template.html     # 内嵌样式的通用 HTML 模板
└── references/
    └── summary-layout.md        # 摘要分层、宫格设计与模板填充方法
```

模板保留占位符供生成时填充；最终交付的 HTML 应全部替换或删除占位符，并核对内容、来源、离线可读性和窄屏排版。

本仓库只包含通用规则、模板和设计参考，不包含用户录音、真实转写稿、测试报告或本地模型文件。
